# Titanic Survival Prediction Using Machine Learning

## Overview

This project predicts whether a passenger survived the Titanic disaster using Machine Learning techniques.

The project demonstrates the complete machine learning workflow, including:

* Data Cleaning
* Feature Engineering
* Data Preprocessing
* Model Training
* Model Evaluation
* Performance Visualization

## Dataset

Titanic Dataset from Kaggle

Features used:

* Pclass
* Sex
* Age
* SibSp
* Parch
* Fare
* Embarked

Target Variable:

* Survived (0 = No, 1 = Yes)

## Machine Learning Algorithms

### Decision Tree Classifier

Accuracy: 79.0%

### Random Forest Classifier

Accuracy: 79.89%

AUC Score: 0.8951

## Evaluation Metrics

* Accuracy Score
* Confusion Matrix
* Classification Report
* ROC Curve
* AUC Score

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-Learn
* Matplotlib
* Seaborn

## Project Outcome

The Random Forest model achieved the best performance with an accuracy of 79.89% and an AUC score of 0.8951, demonstrating strong predictive capability for Titanic survival prediction.
